## [0.1.0] - 2026-10-07

### Added

- Paper-first market discovery, wallet activity, thesis, consensus, sizing, and exit workflows.
- Short-horizon latency engine with directional, complete-set, related-market, and temporal-maker research.
- VWAP, latency, slippage, depth-haircut, queue, and partial-fill execution models.
- Canonical Strategy Truth registry and execution-epoch separation.
- Validation gates for sample size, market-day coverage, PnL, drawdown, concentration, and lower-bound EV.
- Guarded dry-run and live-pilot order paths with geoblock, reconciliation, heartbeat, and risk checks.
- Compact operations dashboard and JSON state endpoint.
- Automated test and lint workflow for Python 3.10 through 3.13.
